Exactly Once Results

Support agents working whole shifts at four fake companies. A shift passes only if every chat in it ends with the right money issued and the right things escalated, checked against the ledger.

Select a column heading to sort. Select a shift count to open those runs.

Shifts passed (pass@1)
Short and long shifts, 24 in all, one attempt each. Every chat in the shift has to be right.
Contested, Gauntlet, Unclear, Audit
Harder shift types added later, 12 of each. A count out of fewer than 12 means only part was run.
Large takeover, Tone
Large takeover: a 64-row batch with five repeated-customer rows. Tone: sarcastic or hostile customers whose literal words point the wrong way.
Styled
Eight ordinary chats under a strict 24-rule style guide, checked by patterns. A chat fails if any message breaks any rule.
Limited memory
The same model and shifts, but every chat starts with a fresh context and only the notes the agent chose to save (1,200 characters).
Contested, finished
In a contested shift another session may still be paying from the same list, so stopping and escalating counts as a pass. This column counts only shifts where the agent also finished the batch.
Chats right
Share of individual chats handled correctly in the short and long shifts.
All 3 seeds / Any of 3
Each company and shift length was generated three times. Of the 8 combinations: how many the model passed every time, and how many at least once. These are three different shifts, not three attempts at one.
Per 100 chats
Across every chat the model was run on: money issued that should not have been, eligible requests refused, and required escalations missed.
What is missing
Each model was run once, so there is no pass@k over repeated attempts and no error bar on any number here.
