A benchmark for support agents that move money

FakeCo Bench

An AI agent works a whole support shift at a fake company, issuing refunds and credits that cannot be undone. When the shift ends, we read the ledger.

Leaderboard

A shift passes only if every chat in it is right

Each model was run once on each shift. The score is the share of shifts with no wrong payment, no missed payment and no missed escalation anywhere in them.

Cost against score

What a passed shift costs

Shifts passed on the 24 short and long shifts, against the estimated cost of running one shift. Cost is worked out from token counts at list prices, so treat it as an estimate, not a bill.

The tasks

One task is one shift on the support desk

Customers arrive one after another and share one back office. The agent has a handbook of numbered rules and a handful of tools that do not enforce them. Every shift is generated from a seed, so a new private set of shifts is one command.

Read a real shift

Three of the generated shifts, as the agent meets them: the handbook, then each chat's opening message. The chat type and the right answer are shown here for the reader; the agent sees neither.

Where models fail

The rules are mostly followed. The money is lost finishing someone else's work.

Share of chats each model got wrong, by the kind of work the chat is. Every shift ends with a colleague's half-finished batch whose log disagrees with the record, and that is where most failures are.

Across every shift each model was run on. A dash means the model was not run on a shift containing that kind of chat.

Contested shifts

Safe is not the same as finished

In a contested shift another session may still be paying from the same list. Stopping and escalating does no harm, so it scores as a pass. This table separates shifts passed from shifts where the agent also finished the batch.

Limits

    Run it

    Any model, one command, a verdict for every chat

    The shifts are published on Valkyrie as fakeco/hard@v3. The harness is a bare tool-calling loop, and the same tasks run unchanged under a shell agent such as Claude Code.

    valkyrie run start --agent fakeco-toolcall \ --dataset fakeco/hard@v3 \ --model openai/gpt-6.1-sol --provider modal \ -s OPENAI_API_KEY openai-api-key --concurrency 4
