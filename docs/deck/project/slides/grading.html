The grading

Graded on the ledger, not on the wording

One right outcome per chat. Which line items were paid, how many, to which destination, and whether it was escalated.

Every chat has to be right. One wrong payment anywhere fails the shift. The share of chats right is reported beside it.

Replayable. The world is deterministic given the agent’s actions, so any saved run can be re-graded without calling a model.

What the grader reads, from one real chat

issue_refund L2 qty 1 $18.00

owed: the hand towel set

issue_refund L1 qty 1 $24.00

not owed: nobody asked for it

issue_refund L3 qty 1 $38.00

not owed: nobody asked for it

The agent sandbox cannot read the answer key or edit the ledger: the company runs under a separate account.

Nothing in the hard tier is graded by a model reading a reply. We look at the ledger and the tool log. A shift passes only if every chat in it is right. Because the environment is deterministic, we can replay any saved run and grade it again, which is how we fixed scoring mistakes without paying for reruns.
