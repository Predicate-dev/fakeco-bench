Why another support benchmark

One trap in one chat is solved. Claude Sonnet 4.6 scores 92 out of 92.

Our first version put a single trap in a single short chat: a policy that breaks the norm, a tool that fails quietly, a stale document. It is saturated. Real support work is a shift, and the mistakes that cost money come from what carries over between chats.

We started with the obvious design: one chat, one trap. Sonnet 4.6 got all 92 right and Haiku 4.5 got 89. So the question became what a model that can do each piece still gets wrong when the pieces are strung together.
