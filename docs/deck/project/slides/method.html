Method

A whole shift of work, graded on the ledger

01

A world

Four simulated companies. Each has an eleven-rule handbook, customer records, a ledger, and tools that move balances.

02

A shift

8 or 14 chats over one ledger, written by a seeded generator. Some are single requests. Some hand over a colleague’s unfinished work.

03

A grade

The final ledger and the tool log, compared exactly with a reference solution. There is no judge model.

04

A count

A shift passes only if every chat is right. Each chat is tagged by what it tests, so failures can be counted by type.

108 shifts

14 models

one run each

every run on Valkyrie

Dataset fakeco/hard@v5

3

Four simulated companies, each with a handbook of eleven rules and a set of tools. A seeded generator writes the shifts, and a reference solution produces the answer key. We grade the final ledger and the tool log against that key, exactly. There is no judge model anywhere. A shift passes only if every chat in it is right. Every chat is tagged with what it tests, so we can count failures by type. Fourteen models, all run on Valkyrie.
