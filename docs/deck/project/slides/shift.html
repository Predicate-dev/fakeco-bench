The task

A task is a whole shift at one company

5 to 14 chats, one context

Customers arrive one after another and share one back office. What the agent issued in chat 3 changes what is right in chat 9.

Eleven numbered rules

An approval limit, a rolling 90-day cap, an eligibility window, final-sale lines, a forced destination. Several chats sit exactly on a boundary.

Stories that disagree with the record

A colleague’s handoff note that is wrong. A memo mid-shift that changes two rules. A customer who asks for the same refund twice.

An unfinished job to take over

Every shift ends with a colleague’s half-run batch: 28 rows, a budget, and a log that is wrong in nine different ways.

Four companies: a home-goods store, an airline, a help-desk software vendor and a bank. Every shift is generated from a seed, so a new private set is one command.
